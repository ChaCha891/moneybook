내 자금관리

잔액을 기준으로 급여, 생활비, 상환과 목표를 한눈에 봅니다.

실제 입출금 기록과 직접 수정이 반영된 잔액

기기 동기화

같은 이메일로 PC와 휴대폰에서 로그인하면 변경 내용을 동기화합니다.

연결 확인 중

설치 앱에서 로그인할 때는 메일의 로그인 버튼을 누르지 말고 길게 눌러 링크를 복사한 뒤, 이 앱의 링크 칸에 붙여넣으세요. 링크는 한 번만 사용할 수 있습니다.

급여 입금 확인

실제 급여를 입력하면 현재 잔액에 자동으로 더하고, 예상 현금에는 중복 계산하지 않습니다.

월별 자금 흐름

현재 잔액을 시작점으로 예정된 항목을 더하고 뺀 예상치입니다. 금액을 클릭하면 항목별 내역을 볼 수 있습니다.

내 항목

빚, 주식계좌 목표, 예정 지출과 수입을 직접 관리합니다.

계산 기준

고정비에는 엄마 상환액을 중복해서 넣지 않았습니다.

기본 설정

입금과 지출이 반영된 실제 통장 잔액을 입력해 주세요.
토·일요일이면 직전 금요일에 입금됩니다. 월말을 넘으면 그달 말일을 기준으로 계산합니다.
적용 시작 월을 추가하면 그달부터 다음 변경 월 전까지 해당 실수령액을 사용합니다.
기존 금액에서 별도 빚 상환을 제외한 금액
급여와 예정 수입에서 고정비·기름값·빚·목표 등을 뺀 금액의 40%, 최대 30만 원을 1만 원 단위로 추천합니다. 담배·외식 등 개인 지출은 용돈에 포함됩니다.
추천 상환액에서 이 금액을 남기는 기준입니다.
현재 잔액에서 앞으로 예정된 금액을 계산할 첫 월입니다. 실제 잔액을 갱신하면 현재 월로 자동 이동합니다.
현재 잔액은 실제 잔액입니다. 이미 받은 급여와 납부한 항목은 각각 ‘완료’로 표시해 주세요. 이번 달에 이미 쓴 고정비·기름값·용돈은 아래 잔액 수정 화면에서 남은 예산을 조정할 수 있습니다.

현재 잔액 갱신

이미 통장에서 빠진 금액은 현재 잔액에 반영되어 있으므로, ‘앞으로 나갈’ 칸에서는 제외해 주세요. 빚과 다른 항목은 각 카드의 V/X로 따로 처리합니다.
